# Sketch map view

From the sketch-blueprints review: once notes carry `->` links, an `m` screen could show only the notes' targets, one column per folder (the boundary) and one card per file, ordered so callers sit left of callees. Moving onto a card highlights what it uses and what uses it, rather than routing lines that turn to spaghetti past a few nodes, and column headers count cross-folder links. Deferred until links have been used on a real feature, since the plan view and the Mermaid export cover most of it.
